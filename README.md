\# 🎯 Tracker App — Mock Login Discord



Aplikasi edukasi: form login bergaya Discord dengan deteksi perangkat, GPS, dan webcam capture. Dilengkapi dashboard admin.



\## ✨ Fitur



\- 🎨 Form login Discord (dark theme)

\- 💻 Deteksi perangkat (OS, browser, resolusi, CPU, RAM)

\- 📍 Deteksi GPS (dengan izin user)

\- 📸 Snapshot webcam (dengan izin user)

\- 🔐 Login admin + session

\- 📊 Dashboard admin dengan 3 chart

\- 🔍 Detail modal (klik foto)

\- 🗑️ Hapus capture per item

\- 🌙 Dark/Light mode toggle

\- 🔔 Notifikasi real-time

\- 📥 Export CSV

\- 📦 Backup ZIP

\- 📱 Responsive mobile
